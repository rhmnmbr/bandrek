# AGENTS.md — Bandrek

Always-on rules for AI agents in this repo. This file stays short on purpose; details live in `docs/`. Read the files listed under "Read before any task" at the start of every new session.

## What this is

Bandrek is a Windows desktop app (Tauri) for a single bimbel (tutoring center). Operators schedule learning activities, record attendance, and track which student has covered which material. Several operators share one server (ASP.NET Core + PostgreSQL on a VPS).

## Hard rules

- Work only inside the folder the current task names. Never edit `docs/prototype/`.
- Build idiomatic React from design-system components, arranged like the prototype. Do not port the prototype's HTML or JavaScript.
- UI components never compute business rules: derived status, allowed actions, conflicts, matrix cell state. They render fields provided by the data layer. The server will own these rules.
- Do not add features, fields, screens, or controls that are not in the prototype or the docs. Propose them and wait.
- Stop at every checkpoint in the task brief and wait for approval before continuing.
- **Versions: always the latest stable release** of every library, framework, and toolchain. Never alpha, beta, RC, canary, nightly, or preview. For Node.js, "stable" means the latest **LTS** line, not Current.
- **Look versions up, never recall them.** Before installing or upgrading anything, check the registry for the actual latest stable version (`npm view <pkg> version`, crates.io, NuGet). Version numbers from memory are outdated.
- npm only. Commit lockfiles. Ask before adding any library not listed in `docs/ARCHITECTURE.md`.
- Toolchain versions live in version files, not in instructions: `desktop/.nvmrc` (Node), `desktop/src-tauri/rust-toolchain.toml` (Rust), `server/global.json` (.NET SDK). Changing them is a deliberate, separate commit.
- If `node`, `npm`, `cargo`, or `dotnet` is not found, the machine's version manager is not initialized in your shell. Stop and tell me. Never install a runtime globally to work around it.
- Never push. Commit only after a checkpoint is approved.
- The host machine is Windows. Keep scripts cross-platform.

## UI conventions

- UI language is Bahasa Indonesia. Labels in sentence case.
- Dates in Indonesian format (`Senin, 14 Sep 2026`), 24-hour time, weeks start on Monday.
- Minimum window 1366×768; must also work at 1920×1080. Desktop only, mouse and keyboard.
- Keyboard: Ctrl+N new kegiatan, Ctrl+S save, Esc closes panel or dialog (confirm first if there are unsaved changes).
- Never show status by color alone — add an icon or text.
- Every scrollable table or list has a max height and a sticky header. Nothing grows without bound.

## Domain terms that are easy to get wrong

- **Subjek** — a person involved in a kegiatan other than the students (tutor, guardian, assistant). It is **not** a school subject. A school subject is **mata pelajaran (mapel)**; its topics are **materi**.
- **Kegiatan** — a scheduled activity. **Realisasi** — the record of what actually happened, mainly attendance.
- **Kelas** — a named group of students used to fill a kegiatan quickly. Not a physical room; a room is **ruangan**, inside a **tempat**.
